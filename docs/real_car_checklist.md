# 실차 확인 목록 (시뮬로는 알 수 없는 것)

전제: 미리 아는 것은 **평면 트랙 맵뿐**. 칸막이·장애물·라바콘·사람 위치는 모름 → 전부 라이다/카메라로 판단.
아래 항목이 틀리면 시뮬에서 되던 것이 실차에서 안 된다. 월요일 첫 주행 전에 위에서부터 확인.

## 1. 라이다가 물체를 실제로 보는가 (가장 중요)
- [ ] **라이다 높이 vs 물체 높이.** URDF `lidar_z` 0.116 m 는 미확인 값. 종이컵(보통 9~10 cm)이 스캔 평면보다
      낮으면 **라이다가 컵을 전혀 못 봄** → 추월 장애물·라바콘·안전 정지 모두 실패.
      확인: 차 앞 0.5 m 에 컵 1개 → `ros2 topic echo /scan` 또는 네비 창 분홍 점에 컵이 찍히는지.
      칸막이, 사람 다리(정지 시험용)도 같은 방법으로.
- [ ] 라이다 장착 방향(yaw)·위치: 곧은 벽/칸막이가 네비 창에서 곧고 맵 선과 평행하게 보이는지.
- [ ] 라이다 사각: 전방 ±110° 만 봄 → **후진(T 주차) 중에는 안전 정지 없음**. 주차 구간에 사람이 들어오면 사람이 멈춰야 함.

## 2. 카메라 위치 보정 (lane_localizer)
- [ ] 카메라 높이·기울기·화각(hfov) 실측 → URDF 맨 위 property. 틀리면 바닥 투영이 틀려 선 점이 맵 선에서 어긋남.
      확인: 차를 선 위에 세우고 네비 창 `d` → 연두 점이 맵 선 위에 겹치는지, match score 1 cm 안팎인지.
- [ ] 선 색(HSV) — 현장 조명에서 다시 맞춤 (`yellow_h`, `white_v_min`, `gray_v` …). 바닥 반사광이 흰색으로 잡히는지.
- [ ] 회색 선(라바콘 구간) 색이 검은 바닥/판 밖 바닥과 구분되는지. 안 되면 `use_gray:=false`.
- [ ] 트랙 판 밖 바닥은 자동으로 버림(`map_margin`). 판 위치가 맵 원점과 맞아야 함 → 출발 위치 프리셋 확인.
- [ ] 보정 거부가 계속 나오면(/localizer/status `reject`) 원인: 색 기준, 카메라 자세, 맵과 실제 트랙 차이.

## 2-1. 출발 전 자리 맞추기 (lane_localizer init_align)
- [ ] 출발 구역에 놓고 drive.launch → 네비 창 위에 `START ALIGN OK: dx .. dy .. dyaw ..` 가 떠야 출발함.
      빨간 글씨면 이유대로: `re-place`(프리셋에서 8 cm 넘게 틀어짐 → 다시 놓기 또는 start_poses.yaml 확인),
      `no match`/`too few line points`(카메라 자세·색 기준 확인).
- [ ] 출발 위치 프리셋(`asw_bringup/config/start_poses.yaml`)을 실제 출발 구역 가운데로 실측해서 맞춤.
      차선이 0.4 m 간격으로 되풀이돼서, 30 cm 넘게 잘못 놓으면 옆 차선을 '맞다'고 착각할 수 있음 (8 cm 제한으로 대부분 막힘).
- [ ] 출발 구역처럼 곧은 차로에서는 앞뒤 위치는 선으로 못 맞춤 → 앞뒤는 프리셋 그대로. 첫 정지선에서 카메라로 맞춰짐.
- [ ] 자리 맞추기 없이 출발해야 할 때: `drive.launch init_align:=false`.

## 3. 안전 정지 (pure_pursuit)
- [ ] 경로 띠 반폭 `safety_half_width` 0.15 m. **라바콘이 경로 중심에서 0.15 m 보다 가까우면 계속 서 있음**
      (시뮬은 0.21 m). 현장 콘 간격 확인. 좁으면 라바콘 구간을 라이다로 가운데 맞춰 가는 기능이 필요 (아직 없음).
- [ ] 사람 시험: 직선에서 차 앞 0.5 m 에 서기 → 정지, 비키면 1초 뒤 출발.

## 4. 미션 판단 (mission_manager)
- [ ] 칸막이: 정지선에서 멈췄을 때 칸막이가 라이다에 보이는지 (높이·거리). `/mission/status` 에 `막힘(5/5회, N점)`.
- [ ] 칸막이가 경로에서 0.17 m (`branch_half_width`) 밖, 도로 가장자리에 놓이면 '열림' 으로 판단 → 그래도 길을 막으면 안전 정지가 멈춤.
- [ ] 추월 장애물: 4번 정지선에서 2초 안에 3장(`confirm`) 이상 보여야 그 자리에서 차로를 정함. 가려진 두 번째 장애물은 달리면서 찾음.

## 5. 주행 기본
- [ ] Ackermann 모드(motion_mode=1), 바퀴 지름·조향 스케일, 자이로 바이어스(정지 시 자동 추정).
- [ ] 수제작 맵과 실제 트랙 차이: 카메라 보정 탐색 범위 ±8 cm 를 넘으면 못 따라감.
